## How posts work

Every post is a single `.mdx` file in `content/blog/`. The filename becomes the URL, so `hello-world.mdx` lives at `/blog/hello-world/`. The block at the top of the file (between the `---` lines) is the **frontmatter**: title, date, a one-line summary, and tags.

Add `draft: true` to the frontmatter and the post disappears from the site until you remove it.

## Markdown, plus a little extra

Everything you'd expect from markdown works: **bold**, _italic_, [links](https://nextjs.org), lists, quotes.

> "I can bring you in warm, or I can bring you in cold."

> Sound advice for handling production incidents.

Code blocks are highlighted at build time, so there is zero JavaScript shipped for syntax colouring:

```ts title="lib/blog.ts"
export function getAllPosts(): Post[] {
  return readdirSync(BLOG_DIR)
    .filter((f) => f.endsWith(".mdx"))
    .map(loadPost)
    .filter((p) => !p.draft)
    .sort((a, b) => b.date.localeCompare(a.date));
}
```

Inline code like `npm run build` also gets the treatment.
